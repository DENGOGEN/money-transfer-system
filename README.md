# Money Transfer System

**Денежные переводы** — WPF приложение для мгновенных переводов между физическими лицами.

## Технологии
- **Язык:** C# / .NET 6.0
- **Платформа:** WPF (Windows Presentation Foundation)
- **IDE:** Visual Studio 2022
- **БД:** Microsoft SQL Server
- **VCS:** Git / GitHub

## Инструкция по сборке и запуску

### Требования
- Windows 10/11
- .NET 6.0 Runtime
- Visual Studio 2022 (для разработки)
